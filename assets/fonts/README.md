# Fonts

By default the pages load **Fredoka** (headings) and **Atkinson Hyperlegible** (body) from Google Fonts.

To self-host: download the `.woff2` files (e.g. from google-webfonts-helper or Fontsource) into this folder, add `@font-face` rules at the top of `assets/css/style.css`, and remove the Google Fonts `<link>` tags from each page head.
