1. Installation

BeadUp is plain HTML, CSS and JavaScript. There is nothing to compile to get started.

  1. Unzip the package. Keep the folder structure as it is.
  2. Open pages/index.html in your browser, or run a local server from the template folder: 
    npx serve .        # or
python3 -m http.server 8080
    then visit http://localhost:8080/pages/index.html. A local server is recommended so the dashboard, forms and downloads behave exactly as online.
  3. Upload the whole folder to your host (Netlify, Vercel, cPanel, S3…). The root index.html redirects to pages/index.html.

Requirements: an internet connection for the CDN files (Bootstrap 5.3.8, Bootstrap Icons 1.13.1, Chart.js 4.5.0, Google Fonts). To run fully offline, download those files into assets/js/plugins/ and assets/fonts/ and update the links in each page's <head>.

Demo login

On pages/login.html any email plus an 8+ character password opens the parent dashboard. The dashboard uses demo data saved in the browser (localStorage). Use Profile & Settings → Demo tools to reset it or to see empty states.

3. Colors, fonts & spacing

All design tokens live at the top of assets/css/style.css under 01. Design tokens. Dark-mode values live in assets/css/dark-mode.css.

:root {
  --bu-primary: #1d4ed8;    /* blue — trust */
  --bu-secondary: #2563eb;  /* blue — achievement, main CTA */
  --bu-accent: #15803d;     /* green — success */
  --bu-level-1 … --bu-level-5   /* belt colors for each level */
}

When you change --bu-primary, also update --bs-primary-rgb in the Bootstrap variable bridge so Bootstrap components match. Keep text contrast at 4.5:1 or more (check with any WCAG contrast checker).

Fonts

Headings use Fredoka; body text uses Atkinson Hyperlegible (designed for readability). To change them, edit the Google Fonts <link> in each page head and the --bu-font-heading / --bu-font-body tokens. Body text is 17px with a 1.65 line height; keep it at 16px or more.

Spacing

Spacing follows an 8px scale: --bu-space-1 (8px) to --bu-space-12 (96px). Bootstrap's spacing utilities (mb-3, gap-4…) are also on a 4/8px rhythm.

Breakpoints

Custom CSS uses the spec breakpoints: <640, 640–1024, 1024–1280, >1280 (see section 30 of style.css). Bootstrap's grid classes keep Bootstrap's own tiers (576/768/992/1200/1400). To make the grid match exactly, compile Bootstrap from Sass with:

$grid-breakpoints: (xs: 0, sm: 640px, md: 768px, lg: 1024px, xl: 1280px, xxl: 1440px);
$container-max-widths: (sm: 600px, md: 720px, lg: 980px, xl: 1240px, xxl: 1320px);

4. Editing content

  • Text: edit the HTML directly. Look for TODO comments at every customization point (search the folder for “TODO”).
  • Brand: the logo mark is an image: assets/images/logo-mark.webp (with a .png fallback), shown at 42×42px — supply it at 96×96px or larger for sharp screens. Favicons are favicon.ico, favicon-32.png, favicon-192.png and apple-touch-icon.png. Change the name in the .brand__name span.
  • Images: replace the WebP placeholders in assets/images/, keeping the same file names and size ratio (the width/height attributes prevent layout shift). Update each image's alt text to describe the new photo. Only use photos of children with written parental consent.
  • Levels, fees, instructors: these appear on several pages. Update Programs, Program Details, Pricing, the Home level strip, and LEVELS / BATCHES at the top of dashboard.js.
  • Stats: trust-row numbers and outcome figures on the Home page are examples. Replace them with your own.

6. Dark mode, RTL & forms

Dark / light mode

The moon button toggles themes. On a first visit the site follows the device setting; once the visitor chooses, the choice is saved in localStorage (bu-theme). A tiny script in each page head applies it before the page paints, so there's no flash.

Right-to-left (Arabic, Hebrew)

The arrows button switches direction. It sets <html dir="rtl"> and swaps Bootstrap for bootstrap.rtl.min.css. Our CSS uses logical properties, so layouts mirror automatically; rtl.css flips directional icons and keeps numbers, phones and emails left-to-right. When you translate, also set lang="ar" or lang="he" on <html>.

Form validation

Add class="needs-validation" to a form. Each field can carry friendly messages:

<input id="email" type="email" required
  data-msg-required="Please add your email so we can reply."
  data-msg-type="Please enter an email like name@example.com."
  aria-describedby="email-error">
<div class="invalid-feedback" id="email-error"></div>

Also supported: data-msg-pattern, data-msg-minlength, data-msg-min, data-msg-max, data-match="#otherField" for confirm-password, and data-strength="fieldId" for the strength meter. Tooltips use Bootstrap's data-bs-toggle="tooltip".

Skeleton loaders & empty states

Wrap a widget in data-skeleton with a .widget__skeleton and a .widget__content child. Call Skeletons.done(el) in dashboard.js once your data has loaded. Empty states use the emptyState() helper.

7. Accessibility, SEO & performance

  • Accessibility (WCAG 2.1 AA): skip link, visible focus rings, ARIA labels on icon buttons, labelled form fields with live error messages, 44px touch targets, one H1 per page, alt text on every image and prefers-reduced-motion support. Re-check contrast if you change colors.
  • SEO: each page has a unique title (≤60 characters), a 150–160 character meta description, canonical URL, Open Graph tags and JSON-LD (EducationalOrganization + LocalBusiness, FAQPage, Course, Event, BreadcrumbList). Replace https://www.example.com/ everywhere (pages, sitemap.xml, robots.txt) with your domain. Login, register, utility and dashboard pages are noindex.
  • Performance: WebP images with fixed dimensions (no layout shift), native lazy loading below the fold, a preloaded hero image, deferred scripts and minified CSS/JS. Host on a CDN with compression for best PageSpeed scores.

Rebuilding the minified files

Pages load *.min.css and *.min.js. After editing the source files, run:

npm install
npm run build

Or, during development, point the page links at style.css / main.js directly.
